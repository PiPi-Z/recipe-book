## 甜心小厨 · 私人菜谱 PWA（新建项目）

用户要求做一个私人菜谱管理网页，密码 092878，可增删改查菜谱、上传图片、自定义分类标签、搜索筛选，甜美女孩风，适配手机平板，同样推送 GitHub。

### 技术方案
- 纯静态 SPA：HTML/CSS/JS，无框架
- 数据存储：**IndexedDB**（js/store.js），菜谱 + 图片（Canvas 压缩到最大边1280、JPEG 0.82 后存 dataURL），适合图片且不受 localStorage 限额
- 密码：前端硬编码 PASSWORD='092878'（js/app.js 顶部），sessionStorage 记住解锁状态；仅防偷看非加密
- PWA：manifest + sw.js + 自绘图标（厨师帽+爱心矢量，Pillow）
- 风格：**甜美手账风**——奶油粉纸底 + 玫瑰粉/薄荷绿/香槟金；核心记忆点=胶带斜贴的拍立得菜谱卡片

### 功能
密码锁屏（6位数字键盘+抖动反馈）、菜谱列表、详情（时间/份量/厨具/分类/食材/步骤/小贴士）、新增编辑（含图片上传压缩）、自定义分类（菜系/方式/工具/场合/标签5维度）、搜索筛选、收藏、锁定。
筛选交互：快捷"全部/收藏" + "筛选"按钮展开维度面板（维度tabs+选项chips）。

### 数据源
无外部依赖，全本地。图标 temp/make_icons.py 用 Pillow 生成。

### 关键踩坑（重要）
1. **密码事件绑定 bug**：initLock 中若 sessionStorage 已解锁会 `unlock(); return;` 跳过事件绑定，导致之后点"锁定"后无法再次解锁。修复：把 pinPad/keydown 监听移到解锁判断之前，始终绑定。
2. 图标爱心用字体字符 ♥ 会显示成方框（字体缺字），改用矢量心形路径绘制。
3. Service Worker 缓存导致开发时改代码看不到效果，需清 caches 再 reload 测试。
4. 全页截图时 fixed 底栏会渲染在中间视口位置，属截图特性非 bug（已给 .app 加 padding-bottom 110px 防遮挡）。
