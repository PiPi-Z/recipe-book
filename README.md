# 甜心小厨 · 我的菜谱手账

一个甜美手账风格的私人菜谱管理 PWA，可安装到手机桌面，支持密码进入、菜谱增删改查、图片上传、自定义分类与标签、搜索筛选，数据本地存储、离线可用。

## 功能

- **密码进入**：进入需输入 6 位密码（当前为 `092878`）。同一会话内刷新免输，点"锁定"可立即上锁。
- **菜谱管理**：记录菜名、食材清单（名称+用量）、烹饪步骤（含小贴士）、烹饪时间、份量、厨具、备注；支持上传菜品图片（自动压缩）。
- **自定义分类**：菜系、烹饪方式、烹饪工具、适用场合、标签五个维度，均可自由增删。
- **搜索与筛选**：按菜名/食材/标签/分类快速搜索，按维度筛选，一键看收藏。
- **甜美手账 UI**：拍立得卡片 + 胶带斜贴的核心视觉，粉彩配色，手机/平板/电脑自适应。

## 安装到手机

- **iPhone / iPad**：用 Safari 打开在线地址 → 底部分享 → 添加到主屏幕。
- **安卓**：Chrome 打开 → 菜单 → 安装应用。

## 本地预览

在本文件夹运行：

```bash
python -m http.server 8901
```

浏览器访问 `http://localhost:8901`。

## 数据说明（重要）

- 所有菜谱和图片保存在**各设备浏览器的 IndexedDB** 中，**不会上传到 GitHub**，也不跨设备同步。手机添加的菜谱只在手机上，电脑添加的只在电脑上。
- 清理浏览器数据会删除菜谱，重要菜谱建议定期手动备份。
- 密码是前端校验，仅用于防偷看，不是加密保护。如需修改密码，编辑 `js/app.js` 顶部的 `PASSWORD` 常量。
